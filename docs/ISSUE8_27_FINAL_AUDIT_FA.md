## شواهد و مرز تأیید اصلاحیهٔ ۰۱

الزام Issue #8: رفع واقعی خطاهای HTTP 403، مدل‌های رایگان، ChatGPT OAuth و پیام‌های محدودیت منطقه، بدون ادعای رایگان بودن نامحدود. مسیرهای بررسی‌شده: `HarnessProvider.kt`، `ModelCatalog.kt`، `DiagnosticReport.kt`، `RotatingKeyProvider.kt`، `ChatGptAccounts.kt`، صفحهٔ حساب‌های متصل و آزمون‌های JVM/Android متناظر. PR #27 پیام خطا را بر اساس کد منطقهٔ صریح از 403 عمومی جدا کرده است. وجود این کد به‌تنهایی اثبات ورود OAuth، دسترسی مدل یا عملکرد روی دستگاه نیست.

آزمون شبکهٔ بدون کلید در ۲۰۲۶-۱۱-۰۵: `scripts/verify_keyless_ai.py --free-inference`؛ کاتالوگ Kilo با HTTP 200 و ۳۸۱ مدل (۱۱ مدل رایگانِ دارای ابزار) باز شد و `kilo-auto/free` با HTTP 200 پاسخ متنی داد. فایل شواهد قابل بررسی: `delivery/issue-8/phase-1/R01-LIVE-KILO-2026-11-05.json`. این آزمون از محیط اجرا انجام شد، نه از گوشی یا شبیه‌ساز، و پایداری یا رایگان‌ماندن سرویس را تضمین نمی‌کند.

آزمون OAuth واقعی ChatGPT و مدل‌های وابسته به حساب، بدون حساب واجد شرایطی که خود کاربر در اپ وارد کرده باشد قابل اجرا نیست. آزمون‌های دستگاهی موجود با ورودی اختیاری `probeChatGpt`/`liveUsageRead` تعریف شده‌اند؛ اجرای پیش‌فرض آن‌ها شاهد اتصال واقعی نیست. هیچ اعتبارنامه، سرویس پولی یا راه دورزدن محدودیت استفاده نشده است. قبل از تأیید ۰۱ باید ورود مجاز، درخواست و پاسخ واقعی، رفتار 401/403/429 و رابط فارسی روی شبیه‌ساز یا دستگاه قابل دسترس با شواهد ثبت شود.
