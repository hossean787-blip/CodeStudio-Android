# تکمیل مرحله‌ای رابط کاربری فارسی و RTL صبا استودیو

**تاریخ:** ۱۴ آبان ۱۴۰۵ / 2026-11-05  
**دامنه:** فقط پروژه صبا استودیو و اصلاحیه‌های رابط کاربری و زبان (موارد ۳، ۴، ۵، ۶، ۱۰ Issue #8).  
**شاخه:** `feature/saba-ui-persian-rtl-20261105`.

## اصلاحات واقعی کد

- زبان فارسی تنها برای **نصب تازه** به‌صورت یک‌باره فعال می‌شود؛ زبان انتخاب‌شده کاربران قدیمی، تنظیم «پیروی از سیستم» و نصب‌های ارتقایافته تغییر داده نمی‌شود.
- با انتخاب فارسی یا عربی، تایپوگرافی Compose در ۲۸ سبک Material 3 از قلم سیستمی سازگار با خط پیوسته و فاصله حروف صفر استفاده می‌کند؛ فایل‌های کد با فونت مونو باقی می‌مانند. فونت اختصاصی بدون مجوز استفاده نشده است.
- ۷ متن کلیدی صفحه ورود به گفت‌وگو، شروع پروژه و اتصال مدل در **۱۱ زبان** به منابع Android منتقل شدند. لوگوی واقعی داخل برنامه جایگزین آیکون عمومی صفحه شروع شد؛ رنگ‌های انتخابی از پالت پوسته گرفته می‌شوند.
- ۶۲ متن پرکاربرد تنظیمات و ارائه‌دهندگان هوش مصنوعی و ۶۸ ترجمه مسئله‌دار چت/آمار/پروژه به فارسی روان‌تر اصلاح شدند.
- برچسب‌های ترمینال، ساخت و آزمایش، گفت‌وگوی جدید، گفت‌وگوهای اخیر و کنترل بایگانی از منابع ترجمه خوانده می‌شوند؛ متن انگلیسی ثابت در پنجره اطلاعات گفت‌وگو و گزارش تعداد فایل تغییرکرده حذف شد.
- نام قدیمی AndroidHarness از بالای پاسخ دستیار حذف و به نام صحیح برنامه تبدیل شد؛ اشاره حقوقی به مؤلف سورس مرجع در مستندات حذف نشده است.
- ترتیب انتخاب زبان با اولویت فارسی، سپس انگلیسی و دیگر زبان‌های پشتیبانی‌شده تنظیم شد.

## معیار آزمون

1. JVM: `SabaFirstRunLocaleTest` — نصب تازه، ارتقا، انتخاب دستی زبان و نبود اطلاعات نصب.
2. JVM: `LocalizationResourcesTest` — پوشش تمام کلیدها و معتبر بودن آرگومان‌های قالب‌های فارسی و سایر زبان‌ها.
3. Emulator: `LocalizationDeviceTest#persianHomeRendersRtlAtLargeTextAndKeepsActionsReadable` — نمایش صفحه شروع در فارسی/RTL با اندازه متن ۱۵۰٪، متن پیشنهادها و حالت اتصال مدل، همراه خروجی تصویر.
4. Android build: `:app:compileDebugAndroidTestKotlin`، `:app:assembleDebug` و `:app:assembleRelease`.
5. Regression: اجرای مجموعه JVM، تست ناوبری، نگهداری پروژه/گفت‌وگو و ساخت Native از GitHub Actions.

**وضعیت گزارش:** این سند معیارهای آزمون و تغییرات انجام‌شده در شاخه را ثبت می‌کند؛ تا زمانی که GitHub Actions آخرین HEAD با موفقیت پایان نیافته باشد، ساخت/آزمون نهایی تأییدشده اعلام نمی‌شود.

## محدودیت‌های واقعی

- تمام متن‌های تولیدشده توسط API/عامل‌های خارجی، محتوای کاربر و نام فنی ابزارها نباید به‌زور ترجمه شوند.
- بررسی انسانیِ تک‌تک صفحه‌های فرعی در تمام اندازه‌ها، نسخه‌های Android و دستگاه فیزیکی به آزمون عملی نیاز دارد.
- فونت اختصاصی تجاری بدون فایل و مجوز معتبر افزوده نمی‌شود؛ فعلاً قلم فارسی سیستمی استفاده می‌شود.
- APK تجاری و ارتقای نصب قبلی با امضای production مستقل از این کار است.
