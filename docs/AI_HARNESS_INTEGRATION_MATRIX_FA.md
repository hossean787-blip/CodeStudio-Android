## معیار پذیرش «ادغام کامل» (برای هر ۱۳ مخزن مستقلاً)

1. درستی محدوده مجوز و متن اعلان حقوقی و وابستگی‌ها تأیید شده باشد.
2. ویژگی‌ها در صورت سازگاری، واقعاً در رابط اختصاصی صبا استودیو فراخوانی و اجرا شوند؛ داشتن دکمه یا لینک کافی نیست.
3. API Key، OAuth، داده‌های محلی و مجوزهای Android با اصل حداقل دسترسی نگهداری شوند.
4. نصب، فعال‌سازی، توقف، خطا و بازیابی هر قابلیت با پیام فارسی و بدون اثر بر قابلیت‌های قبلی کار کند.
5. تست واحد، تست یکپارچگی و تست دستگاه/شبیه‌ساز مرتبط اجرا و نتیجه آن ثبت شده باشد.
6. افزودن هیچ یک از ماژول‌ها باعث حذف یا نقص ویژگی‌های موجود صبا استودیو نشود؛ قبل و بعد از هر تغییر regression تست اجرا شود.
7. نسخه Release غیر Debug امضا شود، روی گوشی نصب شود، و به‌روزرسانی روی نسخه قبلی بدون حذف داده‌ها بررسی شود.

## وضعیت اجرایی این شاخه

- **تکمیل و آزموده‌شده:** ثبت ۱۳ Gitlink، lockfile، آزمون انطباق Gitlink، بررسی اولیه مجوزها.
- **در حال اجرا:** آزمون ساخت و رگرسیون APK پس از افزودن رابط فهرست منابع.
- **اجرا نشده:** آداپتورهای واقعی ۱۳ پروژه، آزمون عملکرد تک‌تک، نصب روی دستگاه.
- **متوقف به‌دلیل مانع حقوقی:** ورود کد Syntac و OpenClaude و هر بخش دیگر با مجوز نامشخص/محدود تا تأیید حقوق نشر.
