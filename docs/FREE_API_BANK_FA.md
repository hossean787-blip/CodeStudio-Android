# صبا استودیو — بانک API رایگان (گام اجرایی ۲۵/۲۶)

تاریخ بازبینی اولیه مستندات سرویس‌ها: ۱۴ آبان ۱۴۰۵ / ۲۰۲۶-۱۱-۰۵.

## مسیر واقعی اپ
تنظیمات ← مدل‌ها و API ← مدیریت ارائه‌دهندگان ← «بانک API هوش مصنوعی رایگان».

بانک یک فهرست آفلاین مبتنی بر راهنمای رسمی است و اجازه می‌دهد سرویس‌های واجد شرایط را جست‌وجو کنید و از همان صفحه به فرم **موجود و رمزگذاری‌شده** ثبت کلید، اتصال و انتخاب مدل بروید. بانک خودش کلید یا حساب ایجاد نمی‌کند و هرگز مدل پولی را بدون اقدام کاربر انتخاب/خریداری نمی‌کند.

## یکپارچه‌سازی با قابلیت‌های موجود
- کلیدها و Proxy در `KeyStoreManager` / EncryptedSharedPreferences ذخیره می‌شوند، نه در متادیتای بانک یا فایل‌های گفتگو.
- فرم اضافه/ویرایش `ProviderSheet` همان مسیر قبلی است؛ بانک فقط برند معتبر و در صورت لزوم ID مدل پیشنهادی را پیش‌انتخاب می‌کند.
- `ProviderKeysEditor` از چند کلید، فعال/غیرفعال‌سازی و چرخش کنترل‌شده پشتیبانی می‌کند.
- `FallbackEditorSheet` مسیر جایگزین، حداکثر چهار مقصد، تعداد تلاش و محدودیت مقصد را **با تأیید صریح کاربر** حفظ می‌کند.
- `FallbackProvider` خطاهای 401/403 را نهایی محسوب می‌کند؛ خطاهای سهمیه/اعتبار و خطاهای گذرا را از هم تفکیک و فقط پیش از تولید خروجی به مقصد مجاز منتقل می‌کند.
- تغییر Provider می‌تواند داده‌های پرامپت را به سرویس دیگری بفرستد؛ شرایط حریم خصوصی و هزینه باید قبل از فعال‌سازی بررسی شود.

## محدودیت‌های اثبات‌نشده
- سقف رایگان به حساب، منطقه، مدل و تاریخ بستگی دارد و با این بانک در لحظه استعلام نمی‌شود.
- هیچ حساب، اعتبار، کلید یا سرویس پولی خودکار ایجاد نمی‌شود.
- آزمون آنلاین با حساب واقعی و گوشی فیزیکی نیازمند اعتبار معتبر و رضایت صاحب حساب است.
- در Cloudflare مسیر شخصی‌سازی آدرس API هنوز در فرم سفارشی کاربران انجام می‌شود؛ دکمه اتصال خودکار نمایش داده نمی‌شود.
- صفحه بانک، جایگزین پیکربندی واقعی Failover نیست و هیچ ادعایی درباره تداوم بی‌وقفه یا دورزدن محدودیت‌ها ندارد.

## آزمون و تحویل
آزمون‌های واحد `FreeApiCatalogTest` چهار دسته اعتبارسنجی آدرس رسمی، تطبیق preset با provider موجود، غیرفعال بودن اتصال گزینه‌های صرفاً راهنما، و جست‌وجو/فیلتر را می‌سنجند.
تأیید ساخت و تست شبیه‌ساز باید از GitHub Actions روی SHA همین تغییرات خوانده شود؛ بدون CI موفق نباید به main ادغام شود.
