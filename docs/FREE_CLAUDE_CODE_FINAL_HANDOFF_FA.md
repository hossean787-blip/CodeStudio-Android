## قابلیت‌های فاقد اجرای تأییدشده

افزوده‌شدن سورس مساوی اجرای Python در Android نیست. **اجرای سرور FastAPI، اجرای launchers نسخه‌های دسکتاپ Claude Code/Codex/Cline/Aider و سایر CLIها، تمام ارائه‌دهندگان دارای پروتکل/OAuth اختصاصی، و Discord از درون APK به‌صورت end-to-end اجرا و تأیید نشده‌اند.** Python 3.14.10 و wheelهای مربوط به معماری Android پیش‌نیاز این مسیر هستند. وجود اسکریپت preflight فقط امکان تشخیص فراهم می‌کند.

مدل‌های ابری بسته به کلید، حساب، سیاست و سهمیه ارائه‌دهنده کار می‌کنند. تعداد preset به‌معنی تضمین دسترسی به آن‌ها یا رایگان‌بودن سرویس‌ها نیست.
