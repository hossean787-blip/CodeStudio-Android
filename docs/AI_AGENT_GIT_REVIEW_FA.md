# مرور امن تغییرات بعد از ویرایش توسط عامل AI — صبا استودیو

## قابلیت اجرایی

ابزار `ai_cli_delegate` که به Codex، Claude، OpenCode، Gemini، Pi، Qwen و Aider نصب‌شده در محیط پروژه متصل می‌شود، اکنون پس از اجرای دستوری که کاربر اجازه ویرایش داده است، وضعیت Git را نیز با دستور **صرفاً خواندنی** `git status --short` نمایش می‌دهد.

- گزارش فایل‌های تغییرکرده و فایل‌های جدید حداکثر ۸۰۰۰ کاراکتر در همان پاسخ ابزار نشان داده می‌شود.
- اجرای Git با `core.fsmonitor=false` و `core.hooksPath=/dev/null` از راه‌اندازی hookهای محلی یا fsmonitor هنگام گزارش جلوگیری می‌کند.
- گزارش شامل تغییرات **از قبل موجود** نیز هست؛ ادعای اینکه عامل مشخصاً همه این تغییرات را ایجاد کرده، نمی‌شود.
- اگر فضای کاری Git نباشد یا فرمان گزارش شکست بخورد، خود نتیجه عامل حفظ شده و پیام «گزارش Git در دسترس نیست» نشان داده می‌شود.
- بدون اجازه ویرایش، دستور Git اضافه اجرا نمی‌شود.
- هیچ فایل جدیدی `git add`، `commit`، `push`، `reset` یا حذف نمی‌شود.
- خروجی قبل از ارسال به گفت‌وگو توسط `SecretRedactor` تصفیه می‌شود.
- مجوز اجرای Agent قبلی همچنان لازم است و هیچ تغییری در امکان ساخت کلید API یا اکانت داده نشده است.

## معیار آزمون

`AiCliDelegateToolTest` رفتار سه فرمان بررسی نصب/اجرای عامل/مرور Git و عدم وجود فرمان‌های تغییردهنده را می‌سنجد. همچنین خطای Git نباید نتیجه موفق عامل را از بین ببرد. آزمون JVM، ساخت Android و شبیه‌ساز توسط GitHub Actions انجام می‌شود.

**محدودیت:** این قابلیت از بخش Diff و بررسی تغییرات الهام گرفته است ولی انتقال کامل محصول مستقل Mobile-Harness یا ۱۳ موتور دیگر محسوب نمی‌شود؛ اجرای واقعی روی دستگاه نیازمند CLI نصب و احراز هویت‌شده است.
