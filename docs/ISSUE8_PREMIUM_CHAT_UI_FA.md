# بازطراحی مرحله اول UI صبا استودیو (Issue #8)

مبنای سورس: شاخه اصلی پس از ادغام آزموده‌شده لوگوی PR #50. محدوده فقط UI صبا استودیو؛ سورس یا طراحی پروژه دیگر استفاده نشده است.

- صفحه شروع: پیش‌زمینه روشن با هاله ملایم، نشان اختصاصی صبا، بخش شروع سریع، کارت‌های جمع‌وجور و لمس آسان.
- گفتگو: حباب پیام روشن و خوانا؛ ورودی با سطح شفاف و مرز مشخص؛ منوی کناری خواناتر و برند یکپارچه.
- حریم خصوصی: Provider raw-thinking text دیگر در بخش گسترش‌یافته رندر نمی‌شود، چه در پیام ذخیره‌شده چه حین جریان. خلاصه فعالیت و وضعیت ابزارها حفظ می‌شوند. شمارنده‌های فنی تفکر از مسیر اصلی چت حذف شده‌اند.
- فارسی و انگلیسی: متن‌های جدید در فایل‌های منابع هر دو زبان قرار دارند.
- شواهد: آزمون واقعی Compose در شبیه‌ساز Android برای متن فارسی/RTL و PNG صفحه خانه در `issue8/ui-redesign/home-fa-rtl-light.png`، آزمون عدم نشت متن تفکر حتی پس از بازشدن پنل؛ ادغام تنها پس از عبور تمام CIهای Android و Native.
- این مرحله بازطراحی صفحه گفتگو، خانه و سایدبار است؛ تغییر کلیه صفحات تنظیمات یا آزمون مستقیم گوشی شخصی کاربر انجام نشده. نسخه تجاری اعلام نشود.
