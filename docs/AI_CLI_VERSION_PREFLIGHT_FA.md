# پیش‌بررسی نسخهٔ CLIهای نصب‌شده — Issue #9

## محدوده
یک قابلیت کوچک و مستقل برای مسیر اجرای CLIهای نصب‌شدهٔ کاربر (الهام از مدیریت عامل‌های پروژهٔ and-code با مجوز ثبت‌شدهٔ MIT). **هیچ کد خارجی کپی یا بسته‌بندی نشده است.** این PR صرفاً نسخهٔ ابزارهای موجود در محیط Linux/SSH همان پروژه را با تأیید کاربر شناسایی می‌کند.

- دکمهٔ فعلی «بررسی عامل‌های نصب‌شده» ابتدا `command -v` را اجرا می‌کند؛ فقط برای CLI پیدا‌شده، فرمان ثابت `<allowlisted-cli> --version` با سقف ۴ ثانیه و ۵۱۲ بایت خروجی فراخوانی می‌شود.
- تنها یک شماره‌نسخهٔ عددی محدود از **خط اول** خروجی استخراج و کنار وضعیت نصب نمایش داده می‌شود؛ متن خام، توکن، خطا یا مسیر محیط نمایش/ذخیره نمی‌شود.
- نتیجهٔ هر پروژه مستقل است و با تعویض پروژه پاک می‌شود. عدم تشخیص نسخه، اجرای عامل را مسدود نمی‌کند و به معنی نصب‌نبودن نیست.
- این بررسی **احراز هویت، مجوز سرویس، سازگاری نسخه، مدل محلی، یا اجرای موفق درخواست AI را تأیید نمی‌کند**. CLI خارجی ممکن است رفتارهای اختصاصی خودش را داشته باشد؛ اجرا فقط با اقدام صریح کاربر آغاز می‌شود.

## آزمون
- `AiRuntimeBridgeTest.versionProbeUsesOnlyFixedCliNamesAndNeverDisplaysRawOutput`: جلوگیری از تزریق شناسهٔ CLI، استخراج نسخهٔ محدود، رد خروجی فاقد نسخه و نشت متن خط دوم.
- `AiRuntimeBridgeDeviceTest.cliVersionPreflightIsAllowlistedOnAndroidWithoutLaunchingCli`: کنترل همان قرارداد روی Android emulator، بدون نصب یا اجرای CLI خارجی.
- GitHub Actions باید آزمون JVM، ساخت Debug و Release آزمایشی، Android emulator و Native/JNI را برای **آخرین HEAD** موفق کند. تا آن زمان PR در حالت Draft می‌ماند.

## حقوق و محدودیت‌ها
این قابلیت کد/کتابخانه‌ای از ۱۳ منبع وارد APK نمی‌کند؛ GPL/AGPL/مالکیتی را بازنشر نمی‌کند. برای اثبات نسخهٔ واقعی، CLI باید توسط کاربر روی دستگاه نصب شود. اجرای مدل، ورود به حساب، API Key، گوشی فیزیکی و امضای production همچنان آزموده نشده‌اند.
