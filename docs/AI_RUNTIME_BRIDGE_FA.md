# صبا استودیو — پل عامل‌های کدنویسی و ۱۳ منبع AI

تاریخ: ۱۴ آبان ۱۴۰۵ / ۲۰۲۶-۱۱-۰۵  
محدوده پیاده‌سازی: توسعه جداگانه در `feature/ai-runtime-bridge-20261105`.

## چیزی که واقعاً کار می‌کند

بخش «تنظیمات ← افزونه‌ها ← منابع هوش مصنوعی» دو مسیر مستقل دارد:

۱. **منابع:** هر ۱۳ مخزن به نسخه مشخص Git در Saba Studio متصل‌اند. با تأیید کاربر، `git clone` روی پروژه مستقل ساخته می‌شود، SHA کنترل می‌شود و پوشه ناقص در صورت خطا پاک می‌شود. برای منابع با محدودیت یا مجوز نامشخص، تأیید مالکیت/مجوز قبل از دریافت الزامی است. این کار سورس را دریافت می‌کند، نه اینکه اپ ثالث را کامپایل یا اجرا کند.

۲. **پل اجرایی عامل‌ها:** محیط ترمینال پروژه را برای هفت دستور زیر بررسی می‌کند و فقط در صورت نصب و درخواست کاربر، یک وظیفه را به عامل ارسال می‌کند:

| موتور | دستور بررسی | حالت فقط خواندن | اجرای وظیفه |
|---|---|---|---|
| Codex | `command -v codex` | `codex exec --sandbox read-only` | `codex exec --sandbox workspace-write` |
| Claude Code | `command -v claude` | `claude -p --permission-mode plan` | `claude -p --permission-mode acceptEdits` |
| OpenCode | `command -v opencode` | تأیید نشده | `opencode run` |
| Gemini CLI | `command -v gemini` | تأیید نشده | `gemini -p` |
| Pi | `command -v pi` | تأیید نشده | `pi -p` |
| Qwen Code | `command -v qwen` | تأیید نشده | `qwen -p` |
| Aider | `command -v aider` | تأیید نشده | `aider --message` |

**محدودیت‌های امنیتی:** موتور فقط از فهرست ثابت انتخاب می‌شود؛ ورودی کاربر به‌صورت یک آرگومان نقل‌قول‌شده به CLI منتقل می‌شود، نه عبارت Shell. در حالت بدون مجوز ویرایش، فقط Codex و Claude با flag مناسب راه‌اندازی می‌شوند؛ پنج عامل دیگر بدون تأیید ویرایش اجرا نمی‌شوند (در حال حاضر ۵ عامل دیگر از هفت عامل). هیچ `curl | sh` یا نصب خودکار، bypass مجوز، کلید جعلی یا تغییر مخفی تنظیمات اتفاق نمی‌افتد. محتوای خروجی حداکثر ۲۴٬۰۰۰ کاراکتر و زمان اجرای هر فرمان حداکثر ۱۸۰ ثانیه است. خروجی در همین نمای UI نگه داشته می‌شود، نه به GitHub ارسال می‌شود و نه در گزارش پروژه ذخیره می‌شود.

## تفاوت پل با انتقال کامل ۱۳ محصول

- Lyra-Code، AndCode، TermFold، AndroidAssistant، Mobile Harness، AntiGem، Syntac، Pocket Pi، Zafiro، androidagent، mobileKinetic، OpenClaude Android و Droid Harness هرکدام یک سیستم مستقل هستند؛ بعضی بیش از صدها مگابایت فایل برنامه و محیط Linux دارند.
- قابلیت برنامه‌هایی که CLI دارند، تا حدی از طریق پل مشترک قابل استفاده می‌شود؛ **برابری تمامی قابلیت‌ها ثابت نشده است**.
- APIهای کنترل دستگاه، مجوزهای حساس Android، RAG/ONNX، Termux/PRoot، موتورهای GPU، سرویس‌های Companion و UIهای اختصاصی هنوز به آداپتور و آزمون جداگانه نیاز دارند.
- ترمینال/منابع روی گوشی واقعی و احراز هویت CLIها هنوز با دستگاه و حساب کاربر آزمایش نشده‌اند.
- مجوزهای اختصاصی ادعایی کاربر برای بازنشر عمومی فایل‌های مالکیتی در خود مخزن ثبت نشده‌اند؛ کد با وضعیت حقوقی مبهم داخل APK کپی/بازنشر نشده است.
- یک نسخه Debug یا آلفای Release، بدون آزمون نصب و صحت کلید امضای پایدار، «نسخه نهایی تجاری» نیست.
